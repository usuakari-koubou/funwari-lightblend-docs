# ふんわり消灯ギミック コンポーネントガイド

ふんわり消灯ギミックに含まれるコンポーネントの一覧と、それぞれの設定項目をご説明します。

ほとんどの値は付属のエディタウィンドウで自動設定されるため、通常は手動で触る必要はありません。
**「何を変えたら何がどう変わるのか」を確認したいとき**にこのガイドをご参照ください。

---

## メインウィンドウの設定

`Tools > ふんわり消灯ギミック > メインウィンドウ` から開きます。上部の「ガイド」と「ダッシュボード」で表示を切り替えます。

- **ガイド**: 「準備」「シェーダー変換」「振り分け」「ペア生成」「ベイク」「仕上げ」「調整」を順に操作します
- **ダッシュボード**: 全工程の完了、未実行、再実行が必要な状態をまとめて確認します

### ライトマッパー選択

「ベイク」ステップの「ライトマッパー:」で選びます。

| 選択肢 | 動作 |
|-------|------|
| **Bakery** | Bakery を使ってベイクします。未導入の場合は選べません |
| **Unity Builtin** | Unity 標準ライトマッパーを使います |

ベイクサイクルの途中で変更すると、点灯用と消灯用のライトマップが不整合になる場合があります。変更する場合は Step 1 からやり直してください。

### 一括実行とチェックポイント

「ベイクを通しで実行する」はベイクの4工程を順に進めます。「消灯した見た目を途中で確認する」をオンにすると、消灯側のベイク後に一時停止します。確認後は「確認できたので続ける」を押します。

設定は次の EditorPrefs に保存されます。

| EditorPrefs キー | 型 | 初期値 | 役割 |
|------------------|----|--------|------|
| `UsuakariKoubou.FunwariLightBlend.UI.v1.BakeCheckpoint` | bool | false | Step 2後の確認で一時停止する |
| `UsuakariKoubou.FunwariLightBlend.UI.v1.BakeStartTimeoutSec` | float | 120 | Runner が開始を応答するまでの秒数 |
| `UsuakariKoubou.FunwariLightBlend.UI.v1.BakeWatchdogMin` | float | 45 | 進捗を取得できないベイクの絶対監視時間（分） |

進捗を取得できるベイクでは、600秒間変化がない場合もタイムアウトとして安全停止します。この600秒は固定値です。

> リロード後は実行中だったベイクを自動再開しません。RecoveryRequired として復元操作を提案します。「シーンを点灯状態に戻す」を押してから再実行してください。

### 既存シーンの取り込みバー

旧バージョンでセットアップ済みのシーンでは、上部に「既存シーンの成立済み ○ 工程を完了として取り込めます」と表示されます。

- **取り込む**: 現在の成果物が成立している工程を完了として記録します
- **閉じる**: その時点の案内を閉じます

取り込み対象は「準備」から「仕上げ」までです。シーンを保存してから「取り込む」を押してください。

## コンポーネント一覧

| コンポーネント | 役割 | 配置場所 |
|--------------|------|---------|
| **LightmapChanger** | 全体を制御する本体。点灯/消灯の切り替えを担当 | シーン内に 1 つ |
| **LightmapChanger_ON** | アニメーター連動で「点灯状態」に切り替えるトリガー | スイッチ内部 |
| **LightmapChanger_OFF** | アニメーター連動で「消灯状態」に切り替えるトリガー | スイッチ内部 |
| **Controller_LightmapBlend** | スライダーから明るさを連続的に制御するためのブリッジ | スライダー内部 |
| **LightmapBlendTarget** | ライト/発光を個別に制御するためのマーカー | 各ライト・発光オブジェクトに |
| **ShaderConversionExclude** | シェーダー一括変換から除外するためのマーカー | 除外したいオブジェクトの親に |

> スイッチ内部のコンポーネント（LightmapChanger_ON / _OFF / Controller_LightmapBlend）は、エディタウィンドウから「点灯スイッチを置く（Switch_Light）」「調光スライダーを置く（Slider_Night）」を実行したときに自動的に配置されます。手動で触る必要はほぼありません。

## LightmapChanger（本体コントローラー）

シーンの点灯/消灯を切り替える本体です。エディタウィンドウから「消灯を制御するオブジェクトを作る」ボタンで設置されます。
設定項目が多いですが、大半はエディタが自動設定するので、ご自身で触っていただくのは「クロスフェード設定」と「アンビエント設定」あたりだけです。

### ライトマップ設定

> 「仕上げ」ステップの「消灯時のライトマップを割り当てる」ボタンで設定されるため、通常は触る必要がありません。

| 設定 | 説明 | デフォルト |
|-----|------|----------|
| **lightmapsOff** | 消灯時のライトマップテクスチャ（自動設定） | - |
| **lightmapsOffDir** | 消灯時の方向ライトマップ（Directional Lightmap 用、自動設定） | - |
| **targetRenderers** | ライトマップ切り替え対象のレンダラー（自動検出） | - |
| **lightVolumeIndexOffset** | Light Volume によるライトマップインデックスのずれ補正 | 0 |
| **autoCalculateOffset** | 上記オフセットをランタイムで自動計算する | ON |

### VRC Light Volumes

> アバターなど動くオブジェクトの色味を切り替えるための設定です。エディタの「Light Volumeを検出して割り当てる」ボタンで自動設定されます。

| 設定 | 説明 | デフォルト |
|-----|------|----------|
| **lightVolumeManager** | シーン内の LightVolumeManager（自動設定） | - |
| **lightVolumeInstancesOn** | 点灯時用の Light Volume 群（自動設定） | - |
| **lightVolumeInstancesOff** | 消灯時用の Light Volume 群（自動設定） | - |
| **disableLightProbesOnOff** | 消灯時に Light Probes ブレンドを無効にする | OFF |

**disableLightProbesOnOff について**：
Light Volume の影響範囲外にあるオブジェクトは、デフォルトでは Light Probes（点灯状態でベイクされた値）の影響を受け続けます。「消灯したのに一部のアバターだけ明るく見える」と感じた場合は、こちらを ON にすると改善することがあります。

### アンビエント設定（フォールバック）

> Light Volume が届かない場所の明るさを補う設定です。**消灯時の見た目を微調整するときに、ここをよく触ります。**

| 設定 | 説明 | デフォルト |
|-----|------|----------|
| **useAmbientFallback** | アンビエント光も連動して変化させる | ON |
| **ambientIntensityOn** | 点灯時のアンビエント強度 | 1.0 |
| **ambientIntensityOff** | **消灯時のアンビエント強度** | 0.1 |
| **ambientColorOn** | 点灯時のアンビエントカラー | 白 |
| **ambientColorOff** | **消灯時のアンビエントカラー** | 暗い青灰色 |

**調整のコツ**：
消灯時に「全体的に暗すぎる / 明るすぎる」と感じた場合は `ambientIntensityOff` を、「夜らしい青みが欲しい / もっと暖色にしたい」と感じた場合は `ambientColorOff` を調整してください。Play モード中でも値を変えながら確認できます。

**動作条件（重要）**：
この設定はランタイムに `RenderSettings`（Unity の **Environment Lighting** 設定）を上書きします。

- `ambientColorOn/Off` が反映されるのは **Environment Lighting の Source が「Color」のとき**だけです（Skybox / Gradient のままだと変化が見えません。「仕上げ」ステップに警告が出ます）
- `ambientIntensityOn/Off` は Source が「Skybox」のときの強度倍率ですが、ベイク済みシーンではランタイム変更が反映されない場合があります
- ライトマップを焼いた**静的オブジェクトには影響しません**。Light Volume 範囲外の**動的オブジェクト向けフォールバック**です

### Light/Emission 制御

> 「振り分け」ステップでの操作に応じて自動設定されます。Inspector から手動で触る必要はありません。
>
> 振り分けは「消灯の影響を受けるものを選ぶ」操作です。振り分けなかったオブジェクトは「常時」として扱われるため、シーン内の全てを振り分ける必要はありません。

#### ON グループ（点灯時に光るライト）

| 設定 | 説明 |
|-----|------|
| **blendTargetLights** | ON グループの Light コンポーネント |
| **blendTargetEmissionRenderers** | ON グループの Emission レンダラー |
| **originalEmissionColors** | Emission の元の色（自動記録） |

#### OFF グループ（消灯時に光るライト）

| 設定 | 説明 |
|-----|------|
| **offGroupLights** | OFF グループの Light コンポーネント |
| **offGroupEmissionRenderers** | OFF グループの Emission レンダラー |
| **offGroupOriginalEmissionColors** | Emission の元の色（自動記録） |

| 設定 | 説明 | デフォルト |
|-----|------|----------|
| **emissionPropertyName** | Emission のシェーダープロパティ名 | `_EmissionColor` |

> 一般的なシェーダーは `_EmissionColor` で動作します。特殊なシェーダーをお使いで Emission がうまく切り替わらない場合のみ、シェーダーのプロパティ名に合わせて変更してください。

### Reflection Probe（映り込み）

> エディタの「リフレクションプローブを検出して割り当てる」ボタンで自動設定されます。

| 設定 | 説明 | デフォルト |
|-----|------|----------|
| **useReflectionProbeBlend** | Reflection Probe のブレンドを有効にする | ON |
| **reflectionProbesOn** | 点灯時の Reflection Probes（自動設定） | - |
| **reflectionProbesOff** | 消灯時の Reflection Probes（自動設定） | - |

> ベイクが完了すると、シーンでは点灯側の Reflection Probe だけが有効になります。消灯側はキューブマップをアセットとして参照するため、シーン上で有効にする必要はありません。両方を有効にすると、エディタでどちらの反射が使われるか不定になります。
| **reflectionCubemapsOff** | 消灯時のキューブマップ（レンダラーごと、自動設定） | - |
| **reflectionOffIntensity** | **消灯時の映り込みの強さ** | 1.0 |

**reflectionOffIntensity について**：
消灯時の金属面の映り込みが暗すぎると感じた場合に、1.5〜2.0 くらいまで上げてみてください。

### クロスフェード設定

> 点灯/消灯の切り替えにかかる時間や、切り替え方の見た目を調整します。**よく触る設定です。**

| 設定 | 説明 | デフォルト |
|-----|------|----------|
| **blendDuration** | クロスフェードにかかる時間（秒） | 1.0 |
| **useEasing** | 切り替えに緩急をつける | ON |

#### blendDuration

スイッチ（ON/OFF トグル）で切り替えるときに、何秒かけて変化するかを指定します。

| 値 | 印象 |
|----|------|
| 0.5 秒 | すばやく切り替わる |
| 1.0 秒 | 標準的な速さ |
| 2.0 秒以上 | ゆったり切り替わる |

> スライダー（中間値対応）で操作する場合は、つまみの位置がそのままブレンド値になるため、この設定は影響しません。

#### useEasing

ON にすると、切り替えの始まりと終わりがゆるやかになり、より自然に見えます。
OFF にすると一定速度で切り替わります。通常は ON のままで問題ありません。

### 消灯の見え方（ディミングカーブ / v2.6.0）

> 消灯時に「明るい場所ほど最後まで灯って見える」本物の調光のような見え方にできます。Inspector で直接編集するより、メインウィンドウの「**調整**」ステップにあるスライダーで調整するのがおすすめです。

| 設定 | 説明 | デフォルト |
|-----|------|----------|
| **dimCurveTau** | 「明るい場所の粘り」の内部値（0 で無効 = 従来どおりの均一な消灯）。「調整」ステップのスライダーから設定されます | 0 |
| **lightVolumeRepresentativeLum** | Light Volumes を粘りに連動させるための内部値。「Light Volumeを検出して割り当てる」ボタンを押すと自動計算されます。手動で変更する必要はありません。**Light Volume をベイクし直したときは、このボタンをもう一度押して再計算してください**（古い値のままだとアバターの粘り方が周囲とズレます） | 0 |

#### 明るい場所の粘り（調整ステップのスライダー）

スライダーを上げるほど、照明のまわりの明るい場所が粘ってから消えるようになり、光だまりが照明に向かって縮んでいくような見え方になります。

| 値 | 印象 |
|----|------|
| 0 | 従来どおり（全体が均一に暗くなる） |
| 中間 | ほんのり粘る、自然な消え方 |
| 最大 | 明るい場所がはっきり残る |

> ベイク済みライトマップの上に実行時に掛かるパラメータなので、**ベイク後にいつでも変更できます**（再ベイクは不要です）。
> 「調整」ステップで「ライブプレビュー」をオンにすると、シーンビューに消灯の様子が反映されます。なお、消灯後に残る明かりはシミュレートされません。点灯ライトの消え方のみがプレビュー可能です。
> この効果は「明るい場所と暗い場所の差」を材料にするため、均一に照らされた部屋では変化が控えめになります。ランプやスポットライトの光だまりがあるシーンでよく映えます。

### 同期設定

| 設定 | 説明 | デフォルト |
|-----|------|----------|
| **instantSyncForLateJoiner** | 後から参加した人にも即座に状態を反映する | ON |

ON にすると、ワールドに後から入室したプレイヤーにも、入室と同時に現在の点灯/消灯状態が反映されます。通常は ON のままにしてください。

### デバッグ設定

| 設定 | 説明 | デフォルト |
|-----|------|----------|
| **debugMode** | Console にデバッグログを出力する | OFF |

問題が起きた場合に ON にすると、初期化やブレンドの状態が Console に表示されます。トラブルシュート時のみご利用ください。

## LightmapChanger_ON / LightmapChanger_OFF（状態切り替えトリガー）

スイッチプレファブ（Switch_Light）の内部に配置され、アニメーターの状態変化に連動して LightmapChanger の点灯/消灯を切り替えるためのコンポーネントです。

「点灯スイッチを置く（Switch_Light）」ボタンを押した際に自動配置・自動設定されますので、通常はご自身で触る必要はありません。

### 設定項目

| 設定 | 説明 |
|-----|------|
| **lightmapChanger** | 切り替え対象の LightmapChanger（自動設定） |

> **手動で配置する場合**：制御対象の LightmapChanger を `lightmapChanger` 欄にドラッグ＆ドロップで設定してください。

---

## Controller_LightmapBlend（スライダー連携用）

LuraSwitch2 のスライダーから LightmapChanger の明るさを連続的に制御するためのブリッジコンポーネントです。

「調光スライダーを置く（Slider_Night）」ボタンを押した際に自動配置・自動設定されますので、通常はご自身で触る必要はありません。

### 設定項目

| 設定 | 説明 |
|-----|------|
| **targetLightmapChanger** | 制御対象の LightmapChanger（自動設定） |

> **手動で配置する場合**：LuraSwitch2 のスライダープレファブ内の `====TargetSetting====` オブジェクトにこのコンポーネントを追加し、`targetLightmapChanger` に対象を設定してください。

---

## LightmapBlendTarget（ライト/発光のマーカー）

シーン内のライトや発光オブジェクトに個別にアタッチして、消灯時の挙動を指定するマーカーコンポーネントです。

「振り分け」ステップでの操作に応じて、対象オブジェクトへ自動的に追加されます。

### 基本設定

| 設定 | 説明 | デフォルト |
|-----|------|----------|
| **targetType** | 制御対象の種類 | Auto |
| **blendGroup** | 振り分けグループ | 点灯 |
| **emissionPropertyName** | Emission のプロパティ名 | `_EmissionColor` |

#### targetType

このオブジェクトの何を制御するかを指定します。

| 値 | 内容 |
|----|------|
| **Auto** | Light コンポーネントと Emission の両方を自動判定して制御（通常はこれ） |
| **Light** | Light コンポーネントのみ制御 |
| **Emission** | Emission（発光マテリアル）のみ制御 |

#### blendGroup

このオブジェクトをどのグループに振り分けるかを指定します。

| 値 | 動作 | 例 |
|----|------|-----|
| **点灯** | 点灯時に明るく、消灯時に暗くなる | メイン照明、蛍光灯 |
| **常時** | 状態に関係なく常に同じ明るさ | 装飾 LED、機械のインジケーター、自前アニメで動く看板 |
| **消灯時のみ** | 消灯時に明るく、点灯時に目立たない | 非常灯、星空、蓄光素材 |

> 振り分けはメインウィンドウの「振り分け」ステップで一覧操作します。Inspector で個別に変更することもできます。

---

## ShaderConversionExclude（シェーダー変換からの除外マーカー）

このコンポーネントを親オブジェクトに追加すると、その配下のすべてのレンダラーがシェーダー一括変換の対象から除外されます。

### 設定項目

設定項目はありません。コンポーネントを追加するだけで機能します。

### 使いどころ

- 常に明るく見せたいモニター・TV 画面（消灯時にも周りと一緒に暗くしたくないもの）
- Light Volume を参照する動的投影シェーダーで Emission が動いているオブジェクト（シェーダーを置き換えると動的演出が壊れるため）
- その他、独自のシェーダー演出が組まれていて置き換えたくないオブジェクト

> 通常のワールド家具（壁・床・小物など）は変換した方が自然な見た目になりますので、特別な事情がなければ除外しないことをおすすめします。
>
> 自前のアニメで Emission が動いているオブジェクト（点滅看板など）は、**シェーダー変換は行ってよい**です。代わりに `LightmapBlendTarget` の `blendGroup` を「常時」にすると、Funwari が Emission を上書きしなくなり、自前アニメと衝突しません。

## よく触る設定まとめ

セットアップが終わったあとに、見た目を微調整するためによく触る設定の早見表です。

| 触りたいこと | コンポーネント | 設定項目 |
|-------------|---------------|---------|
| 消灯時の全体的な明るさ | LightmapChanger | `ambientIntensityOff` |
| 消灯時の色味（夜の青さなど） | LightmapChanger | `ambientColorOff` |
| 消灯時の映り込みの強さ | LightmapChanger | `reflectionOffIntensity` |
| 消え方（明るい場所の粘り） | LightmapChanger | 「調整」ステップの「明るい場所の粘り」スライダー（内部値: `dimCurveTau`） |
| 切り替えにかかる時間 | LightmapChanger | `blendDuration` |
| 切り替え時の緩急 | LightmapChanger | `useEasing` |
| 個別のライトの振り分け変更 | LightmapBlendTarget | `blendGroup` |

> Play モード中に値を変えても見た目を確認できます（Play モードを終了すると変更は破棄されますので、確定したい値は Play モードを抜けてから設定してください）。
