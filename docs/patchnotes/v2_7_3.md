# ふんわり消灯ギミック v2.7.3 パッチノート

**〜出る警告を信じられるようにする〜**

実態と違う警告を正し、詰まって先へ進めなくなる経路を塞ぎました。

## ⚠️ 1. 実態と違う警告を出していました

**「Bakery が RNM / SH / MonoSH モードでベイクされている可能性があります」**

この判定は `Assets` フォルダ全体からファイル名に `_rnm` `_sh` `_monosh` を含むテクスチャを探していました。**Bakery に同梱されているサンプル**（`example_directional_RNM_*` など）に当たるため、モードに関係なく警告が出続けていました。`_sh` は `wall_shadow` のような普通の名前にも当たります。

シーンが実際に使っている設定値を読むようにしました。誤検出が無くなり、毎回テクスチャを全部走査する無駄も消えました。

**「Lightmap Compression が無効になっています」**

これは Unity 内蔵ライトマッパーの設定で、Bakery で焼くときは結果に影響しません。それなのに **Bakery を選んでいるときだけ**出ていました。Unity 内蔵を選んだときだけ出すようにしました。

**「ベイクデータが入っていない Light Volume が N 件あります」**

複製元として無効にしてある Light Volume を数えていました。Light Volumes は非アクティブなものをベイク対象から外すため、これは焼かれようがありません。数えないようにしました。

## 🔄 2. 変換とベイクが意味なく「要再実行」になっていました

変換をやり直す必要があるかの判定が、マテリアルの**中身**の変化まで拾っていたため、ベイク中に他のツールがマテリアルへ触るだけで「変換をやり直せ」と出ていました。変換が気にするのは**どのマテリアルとシェーダーが使われているか**だけなので、そこだけを見るようにしました。

> この版で判定のしかたが変わるため、**変換の記録が一度だけ「要再実行」**になります。1回実行し直せば以後は安定します。

## 🆘 3. 緊急用の復元ボタンが押せなくなっていました

v2.7.0 の画面刷新で、旧版にあった「全体をリセット（変換前の状態に戻す）」が落ちていました。復元の処理は残っていたのに、**呼び出す口がどこにも無い**状態でした。

**準備タブに「ツール適用前のシーンを復元する（緊急用）」として戻しました。** どこへ戻るのかが分かるよう、バックアップを取った日時を添えます。

バックアップは「ベイク用のフォルダを作る」を実行したときに1つだけ取られ、以後は上書きされません。**シーンをファイルごと差し替える**ので、バックアップを取ったあとの作業は、ツールと関係のないものも失われます。確認ダイアログでその旨を明示します。

## 🧱 4. 終わったベイクで次のベイクが始められなくなっていました

4工程を終えて後始末も済んだあとに記録だけが残り、そこへプレイモードの出入りが記録されると「要復元」になっていました。戻すものが何も無いのに復元を求め、「シーンを点灯状態に戻す」も押せず、次のベイクも始められない状態です。

終わった記録は復元を求めず、その場で片づけるようにしました。

## 🌑 5. 焼けたのに真っ黒なときに知らせます

光源の設定が足りないと、**ベイク自体は成功したまま中身が空**になります。Bakery は Bakery 用のライトが付いた光源しか使わないため、Unity ライトに何も付けずに焼くとこうなります。

これまでは全工程が「完了」と表示され、仕上げまで進んで初めて気づく状態でした。点灯ベイクの直後に明るさを測り、光が入っていなければ知らせます。

## 🖥 6. ダッシュボードの表示を整理しました

判定の根拠を7枚すべてに出していたため、揃っているカードでは要約と同じことを二度言う形になり、肝心の状態が文字に埋もれていました。**手を入れる必要があるカード（要再実行・警告あり）だけ**に出します。

見直し中の知らせも1箇所にまとめました（従来は7枚が同時に点滅していました）。内部の名前が出ていた文言も書き換えています。

## 更新のしかた

これまでと同じです。古いフォルダを消さずに、新しい `.unitypackage` をインポートしてください。シーンの設定はそのまま残ります。

インポート後、**変換が一度だけ「要再実行」**になります（上記2のため）。実行し直してください。
