# ふんわり消灯ギミック v2.8.0 パッチノート

**〜焼けば、そのまま完成する〜**

工程が7つから6つになりました。**「仕上げ」で手で押していた3つの設定が、ベイクの中で自動的に行われます。**

## 🔁 1. 焼いたら、そのまま完成します

これまでは、ベイクを通しで実行したあとに「仕上げ」工程で次の3つを手で押す必要がありました。

- 消灯時のライトマップを割り当てる
- Light Volume を検出して割り当てる
- リフレクションプローブを検出して割り当てる

**この3つはベイクの中で自動的に行われます。** 押し忘れて成果物が噛み合わないことがなくなります。

1つずつ実行した場合も同じです。割り当ては**それぞれの材料が揃った工程の最後**で行われます。

| 割り当て | 行われる場所 |
|---|---|
| 消灯ライトマップ | Step 3（点灯ライトマップのベイク）の完了時 |
| Light Volume・リフレクションプローブ | Step 4（点灯 Probe & Light Volume）の完了時 |

### ライトマッパーの切り替えが楽になります

Bakery と Unity 内蔵ではライトマップの**枚数も名前も変わります**。これまでは切り替えて焼き直すたびに、割り当てが古いまま残って噛み合いませんでした。

いまは**切り替えて焼き直すだけ**で揃います。

## 🧭 2. 工程が6つになりました

```
準備 / シェーダー変換 / 振り分け / ペア生成 / ベイク / 仕上げ
```

旧「仕上げ」工程は解体しました。中身の行き先は次のとおりです。

| 旧・仕上げの中身 | 行き先 |
|---|---|
| 3つの割り当て | **ベイクへ**（自動） |
| 調光スライダー・点灯スイッチの設置 | **「仕上げ」タブへ**（任意の操作として） |
| 環境光の設定を単色に変える | **「仕上げ」タブへ** |

旧「調整」タブが新しい**「仕上げ」**です。消灯の見え方の調整に加えて、上記の任意の操作が並びます。**どれも「焼いたあとに好みで触るもの」**なので、性質が揃いました。

## 🔍 3. 検査は残しています

「焼いたあとに割り当てがずれた」を見つける検査は捨てていません。**ベイク工程の完了条件に組み込みました。**

ベイクが「完了」と表示されるのは、焼き上がりが揃っていて、**かつ割り当てが噛み合っているとき**だけです。プレイモードの出入りで割り当てが戻った場合も、これまでどおり気づけます。

## 更新のしかた

これまでと同じです。古いフォルダを消さずに、新しい `.unitypackage` をインポートしてください。

**インポート後、ベイク工程が一度だけ「要再実行」になります。** 完了条件に割り当ての検査が加わったためです。焼き直すか、割り当てが既に噛み合っていれば次のベイクで解消します。

旧「仕上げ」工程の記録は自動的に読み飛ばされます。利用者側の作業は不要です。
