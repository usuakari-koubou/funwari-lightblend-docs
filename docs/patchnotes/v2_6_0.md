# ふんわり消灯ギミック v2.6.0 パッチノート

**〜「本物の調光」みたいに、光がすーっと縮んで消えていく〜**

## ✨ 新機能: 収縮する消灯（ディミングカーブ）

いままでの消灯は、部屋全体が同じ割合でスーッと暗くなる「均一フェード」でした。
でも本物の照明を絞ったときって、**遠くの薄暗い場所から先に見えなくなって、
照明のまわりの明るい場所が最後まで粘る**んですよね。光だまりが照明に向かって
縮んでいく、あの見え方です。

v2.6.0 では、これを再現する**「明るい場所の粘り」スライダー**が追加されました。

- 「最終設定」タブの「消灯の見え方」セクションにスライダーが1本増えただけ。
  **追加のベイクは不要**です（Light Volumes をお使いの場合のみ、アップデート後に
  LVセットアップの再実行が1回必要です。下の「アップデート後にやること」をご覧ください）
- スライダーを上げるほど、明るい場所が「粘って」から消えるようになり、
  照射範囲が収縮する本物らしい消灯になります
- **0（初期値）のままなら、今までと完全に同じ見た目**です。アップデートしても
  勝手に見た目は変わらないのでご安心ください
- スライダー調光（LuraSwitch等）でも、ON/OFFトグルのフェードでも効きます
- ライトマップだけでなく、Light Volumes（アバターの明るさ）・ライト・
  発光マテリアルも自然に連動します

## 🔍 シーンビュープレビュー

Playモードに入らなくても、**編集モードのままシーンビューで消灯の見た目を
確認しながら絵作りできる**ようになりました。

- 「最終設定」タブを開くと**自動でライブプレビューが有効**になります
  （面倒なオン/オフ切り替えはありません）
- 「プレビュー (1=点灯 / 0=消灯)」スライダーをぐりぐり動かすと、シーンビューに
  消灯の様子がそのまま映ります。「明るい場所の粘り」との組み合わせをその場で調整できます
- 別のタブに切り替えるか、ウィンドウを閉じれば自動で通常表示に戻ります

> ⚠️ 消灯後に残る明かりはシミュレートされません。点灯ライトの消え方のみが
> プレビュー可能です。最終確認はPlayモードか実機で行ってください。

## ❓ よくある質問: ベイクをやり直す必要はある？

**ありません。** 「明るい場所の粘り」は、ベイク済みライトマップの上に実行時に
掛かるパラメータです。ベイク完了後に「最終設定」タブでいつでも自由に変更できます
（変更のたびの再ベイクや再セットアップは不要です）。

## 🛠 アップデート後にやること

1. パッケージを上書きインポート
2. **Poiyomiをお使いの場合**: メインウィンドウからPoiyomi対応シェーダーを
   **再生成**してください（旧バージョンで生成したシェーダーのままだと、
   Poiyomiの面だけ新しいカーブが効きません）
3. **Light Volumesをお使いの場合**: LVセットアップを**再実行**してください
   （アバターの明るさをカーブに連動させるための値を自動計算します。
   LVをベイクし直したときも再実行してください）

## 🔧 修正・改善

- 完全消灯時にごくわずかな残光が出る可能性があった内部処理を改善しました
- 古い重複Poiyomiシェーダーファイルを削除しました（シェーダー名の衝突予防）

## 📝 注意事項

- **LightmapChanger は1シーンに1個**を推奨します（複数置くと最後に操作した
  1個が全体を制御します。エディタに警告が出るようになりました）
- シェーダーとスクリプトは**必ず両方まとめて**アップデートしてください
- 映り込み（リフレクション）は今バージョンでは従来どおりのフェードです

---

既存シーンへの影響はありません（「明るい場所の粘り」0 = 従来と同一挙動）。
不具合を見つけた場合はバージョン番号（2.6.0）を添えてご報告ください。
