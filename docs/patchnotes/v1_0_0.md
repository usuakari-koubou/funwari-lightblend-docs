# ふんわり消灯ギミック v1.0.0 パッチノート

**〜正式版〜**

ベータ版 (v2.x) から番号を振り直しました。番号の上では v1.0.0 < v2.x ですが、
v1.0.0 が最新です。ベータ版をお使いの場合は、古いフォルダを消さずにそのまま
インポートしてください。

## 📦 有償版になりました

v1.0.0 から有償で頒布します。利用条件は同梱の LICENSE.md にまとめました。
要点だけ挙げると:

- 組み込んだワールドの公開・販売は自由 (クレジット表記も不要)
- ツール本体の再配布・転売は禁止
- 相手も購入者なら、ツールごと共有・納品してよい
- 迷ったら気軽に問い合わせてください (BOOTH のメッセージへ)

ベータ版 (v2.7.3 以前) は MIT License のまま変わりません。

## 🎨 画面を作り直しました

色の役割をひとつずつに絞りました。

- **青** = いま見ている工程
- **オレンジ** = 次に押すもの。**画面にひとつだけ**現れます
- **琥珀の文字** = 注意が要るところ (これまでの塗りつぶしの帯はやめました)

工程を終えると、カードの下に次の工程への近道が出ます。オレンジを追っていけば
最後まで進めます。

そのほか:

- 「振り分け」を操作の順番どおりに並び替えました。完了ボタンは一覧の下に常にあり、
  押せないときは理由が表示されます
- ベイクの「通しで実行」と「1つずつ実行」を同列の選び方にしました。
  1つずつは見た目を確認しながら進みたいときに使います
- 済んだ操作には ✔ が付き、ボタンの文言が「作る」から「作り直す」に変わります
- 緊急用のシーン復元は「どうにもならなくなったとき」に畳みました
