## 画面の見かた

色にはそれぞれ役割があります。

- **青** = いま見ている工程
- **オレンジ** = 次に押すもの。**画面にひとつだけ**現れます
- **琥珀の文字** = 注意が必要な箇所

工程を終えると、カードの下に次の工程への近道が出ます。オレンジを追っていけば最後まで進めます。

- 「振り分け」は操作順に並び、完了ボタンは一覧の下に常にあります。押せないときは理由が表示されます
- ベイクは「一括で実行」と「1つずつ実行（見た目を確認しながら）」のどちらでも進められます
- 完了済みの操作には ✔ が付き、ボタンは「作り直す」表示に変わります
- 緊急用のシーン復元は、準備タブの「どうにもならなくなったとき」にあります

## ベータ版（v2.x）をお使いだった方へ

- 正式版にあたり、番号を v1.0.0 から振り直しました。**番号上は v1.0.0 < v2.x ですが、v1.0.0 が最新です**
- 更新はこれまでと同じです。古いフォルダを消さずに、新しい unitypackage を上書きインポートしてください。シーンの設定はそのまま残ります
- セットアップ済みのシーンを開くと取り込みの案内が出ます。「取り込む」を押すと、成立している工程が完了として記録されます
- ベータ版 (v2.7.3 以前) のライセンスは MIT のまま変わりません
