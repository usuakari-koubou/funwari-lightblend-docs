# ふんわり消灯ギミック クイックスタート

VRChat ワールドの照明を、点灯から消灯までなめらかに切り替えるツールです。
点灯用と消灯用の 2 組のライトマップをベイクし、Light Volume・リフレクションプローブ・ライト・発光も一緒に切り替えます。

![点灯と消灯の比較](images/compare_on_off.png)

動いているところは [デモ動画](https://usuakari-koubou.github.io/funwari-lightblend-docs/) で見られます。

---

## この手順で扱う範囲と所要時間

この手順は、**1 つの部屋を点灯から消灯まで切り替える**最小構成を扱います。
Unity のメニュー `Tools > ふんわり消灯ギミック > メインウィンドウ` を開き、左の 6 つの工程を上から順に進めます。

- 所要時間: 操作は 15 分ほど。ベイクの時間はワールドの大きさとライトマッパー次第です（この手順の部屋は Unity の Progressive で 5 分、Bakery で 3 分ほどでした）。
- 部屋ごとに消灯したい、昼と夜を切り替えたい場合は、工程3 のあとで [部屋ごとに消灯する](rooms.md) / [昼と夜を切り替える](daynight.md) を読んでください。

![メインウィンドウの構成](images/overview.png)

---

## 始める前のチェック

次の 4 つが揃っていれば始められます。揃っていないものがあれば、先にそちらを済ませてください。

| チェック | 確かめ方 |
|---|---|
| 点灯した状態のライトマップがベイク済み | Lighting ウィンドウの Baked Lightmaps にライトマップが並んでいる |
| 壁や床などの静的な物が Static (Contribute GI) | Inspector の Static にチェックがある |
| マテリアルが対応シェーダー（lilPBR / Filamented / Unity Standard / Mochie Standard / Poiyomi Toon World） | 対応表は [Dependencies.md](dependencies.md) |
| VRC Light Volumes がプロジェクトに入っている（シーンに置くかは任意） | VCC のパッケージ一覧 |

Bakery を使う場合は、ライトに BakeryPointLight か BakeryLightMesh が付いていることも確かめてください（Bakery は Unity の Light を見ません）。

**始める前にプロジェクトをバックアップしてください。** このツールは工程1 でシーンのバックアップを取りますが、プロジェクト全体は対象外です。

---

## 工程1: 準備

![工程1 準備](images/step1.png)

目的: 成果物の保存先と、消灯を制御するオブジェクトを作ります。

1. シーンを保存します（未保存のシーンでは工程の進み具合が記録されません）。
2. 「ベイク用のフォルダを作る」を押します。保存先は `Assets/BakeFolder/Scenes/(シーン名)/` に固定です。
3. 「消灯を制御するオブジェクトを作る」を押します。

できた状態: 2 つの行に緑のチェックが付き、下の案内が「次はシェーダー変換です」になります。

---

## 工程2: シェーダー変換

![工程2 シェーダー変換](images/step2.png)

目的: シーンのマテリアルを、消灯に対応した派生シェーダーのコピーに差し替えます。元のマテリアルは変更しません。

1. 「変換対象」の一覧を確かめます。変換したくない物には `Shader Conversion Exclude` コンポーネントを付けます（親に付けると配下ごと外れます）。
2. 「対象のマテリアルをまとめて変換する」を押します。確認が出るので「変換」を押します。

できた状態: 「変換待ちのマテリアルはありません」になります。コピーは `Assets/BakeFolder/ConvertedMaterials/` に入ります。

うまくいかないとき: 一覧に出ないマテリアルがある → [困ったとき](#困ったとき) の「変換対象に出ない」。

---

## 工程3: 振り分け

![工程3 振り分け](images/step3.png)

目的: ライトと発光を「点灯」「常時」「消灯時のみ」に分けます。

| グループ | 意味 | 例 |
|---|---|---|
| 点灯 | 消灯すると暗くなる | 天井の照明、デスクライト |
| 常時 | いつも同じ明るさ | ロウソク、装飾の LED |
| 消灯時のみ | 消灯したときだけ光る | 非常灯、星空 |

1. 一覧が空なら「シーンを再スキャン」を押します。
2. 消灯で暗くしたいものを、行の「→点灯」で点灯の列へ移します。行をドラッグして移してもかまいません。
3. 振り分けなかったものは「常時」として扱われます。全部を振り分ける必要はありません。
4. 一覧の下の「振り分けを完了にする」を押します。

できた状態: 上に「制御対象 N 件を同期済みです」と出て、案内が「次はペア生成です」になります。

うまくいかないとき: 「同期されていません」と出て完了できない → 「振り分けを LightmapChanger に同期する」を押します（Inspector で直接振り分けたときに出ます）。

---

## 部屋ごと・昼夜を使うなら、ここで

工程1 の「使う機能を選ぶ」で「部屋ごとに明るさを変える」「昼と夜を切り替える」をオンにすると、工程3 のあとに「部屋」「昼夜」の工程が現れます。
どちらも**ベイクの前に**設定します。手順は [部屋ごとに消灯する](rooms.md) と [昼と夜を切り替える](daynight.md) にあります。使わない場合はそのまま工程4 へ進んでください。

---

## 工程4: ペア生成

![工程4 ペア生成](images/step4.png)

目的: Light Volume とリフレクションプローブにも、点灯用と消灯用の 2 組を用意します。

1. 「Light Volumeの点灯・消灯ペアを作る」を押します。
2. 「リフレクションプローブの点灯・消灯ペアを作る」を押します。

シーンにどちらも置いていなければ、押さなくて構いません（0 件で成立します）。

できた状態: 「点灯・消灯ペアは生成済み」に緑のチェックが付きます。元の Light Volume とプローブは無効化され、`LightVolume_ON/OFF`、`ReflectionProbe_ON/OFF` の下にコピーができます。

---

## 工程5: ベイク

![工程5 ベイク](images/step5.png)

目的: 消灯用と点灯用のライトマップとプローブを、合計 4 回ベイクします（Light Volume を置いていると 1 回増えます）。ライトマップや Light Volume の割り当ては自動で行われます。

1. 「ライトマッパー:」で使うものを選びます。Bakery を入れていれば既定は Bakery です。Unity の Light だけで作ったシーンでは「Unity Builtin」を選んでください。
2. 消灯の見た目を途中で確かめたいときは「消灯の見た目を確認してから続ける」をオンにします。
3. 「ベイクを実行する」を押します。消灯ベイク → 消灯プローブ → 点灯ベイク → 点灯プローブ の順に進みます。Bakery では開始時にシーンの保存を聞かれるので「Save」を選びます。リフレクションプローブのベイク中は Unity が止まって見えますが、そのまま待ってください。

![消灯確認で止まったところ](images/step5_checkpoint.png)

止まっている間、シーンは消灯した状態です。シーンビューで見た目を確かめ、「確認できたので続ける」を押します。

![消灯した状態の部屋](images/scene_off.png)

できた状態: 「消灯ベイク ✔ 消灯プローブ ✔ 点灯ベイク ✔ 点灯プローブ ✔」と「一括実行: 完了」になり、シーンは点灯した状態に戻ります。左の工程5 に ✔ が付き、案内が「次は仕上げです」になります。

うまくいかないとき: ボタンが押せない → 押せない理由が下に出ます。「Bakery は Unity のライトを見ません」なら、ライトマッパーを Unity Builtin にするか、ライトに Bakery のコンポーネントを付けます。途中で止まった → [失敗したときの復元](#失敗したときの復元)。

---

## 工程6: 仕上げ

![工程6 仕上げ](images/step6.png)

目的: 消え方を決めて、シーンに書き込みます。

1. 「明るい場所の粘り」を決めます。0 なら全体が均一に暗くなり、上げるほど明るい場所が最後まで灯って見えます。
2. 「ライブプレビュー」をオンにして「プレビュー (1=点灯 / 0=消灯)」を動かし、見え方を確かめます。
3. 「消灯カーブをシーンに適用する」を押します。

操作用のスイッチを置くなら「ボタン配置（任意）」から置けます（LuraSwitch2 が必要です）。

できた状態: 案内が「全工程完了です」になります。「ダッシュボード」で全工程が「完了」になっているか見られます。

![ダッシュボード](images/dashboard.png)

---

## 確認する

1. **プレビュー**: 上の「プレビュー」を押し、「プレビューを開始」→「全体の点灯」を動かします。Play モードに入らずに、静的な物のライトマップと映り込みの切り替えをシーンビューで確かめられます。Light Volume・リアルタイムライト・発光・スカイボックスは映りません。
2. **Play モード**: 発光や Light Volume を含めた実際の見え方を確かめます。「調光スライダーを置く」で置いたスライダーを動かすか、消灯を制御するオブジェクトの Inspector で値を変えます。
3. **VRChat の Build & Test**: 最後にアバターを入れて確かめます。アバターの明るさは Light Volume で変わります。

---

## 失敗したときの復元

- **ベイクが途中で止まった**: 工程5 に「前回のベイクが途中で止まりました」のカードが出ます。「シーンを点灯状態に戻す」を押してから、ベイクをやり直します。
- **元のシーンに戻したい**: 工程1 の「どうにもならなくなったとき」にある「ツール適用前のシーンを復元する（緊急用）」を押します。戻る先は「ベイク用のフォルダを作る」を押した時点のバックアップです。バックアップを取ったあとの作業は、ツールと関係ないものも消えます。
- 成果物はシーンごとのフォルダに分かれています。別のシーンでベイクしても、開いているシーンの工程は影響を受けません。

## 困ったとき

| 症状 | 対処 |
|---|---|
| 変換対象に出ないマテリアルがある | 対応シェーダーでないか、Static (Contribute GI) が付いていません。対応表は [Dependencies.md](dependencies.md) |
| Poiyomi の面が消灯しない | Poiyomi は Lighting Type が Realistic のときだけライトマップを読みます。マテリアル側で Realistic にします |
| Bakery で「対応しているのは Half と Dominant Direction」と出る | Bakery の Directional mode を None か Dominant Direction にします。RNM・SH・MonoSH には対応していません |
| Bakery で暗い所が濁る | Bakery の GI Samples を 64 に上げます（既定の 16 では間接光のサンプルが足りません） |
| 自前のアニメーションで発光を動かしている物がある | 「常時」に振り分けます。「点灯」に入れると消灯の制御と取り合いになります |
| 工程が「要再実行」になった | その工程の入力（振り分け、ライト、マテリアルなど）が変わっています。表示された工程からやり直します。ベイクは再ベイクするまで戻りません |
| 全部の状態をまとめて見たい | `Tools > ふんわり消灯ギミック > 契約チェック（読み取り専用）` |
