## メモ

- 「動作確認済み」= 実際に Unity / VRChat 上で操作して期待どおり動いたバージョン
- 「確認待ち」= コードのコンパイルは通っているが、まだ実機で操作確認していないバージョン
- 確認が取れたら、行を「動作確認済み」テーブルに移し、確認日・環境を記入してください
